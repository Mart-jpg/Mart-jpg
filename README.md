## Selected work

### CBGI · Programme discovery and registration

I built the website for a UK–Nigeria creative education initiative. The site gives prospective participants a clear path from learning about the Lagos programme to registering interest, and gives potential partners a direct way to get in touch.

[Explore the live CBGI website](https://cbginitiative.vercel.app/)

### MARTINO · E-commerce storefront

My work on MARTINO includes the Shopify storefront and the customer journey beyond checkout. One focus is helping customers find order tracking from the live store.

[Explore the MARTINO storefront](https://themartinobrand.com/)
